# FinApp — Finanzas Personales

Una aplicación web moderna, interactiva y responsiva para gestionar finanzas personales en móvil (Android / iPhone) y escritorio.

## Características
1. **Dashboard Financiero**: Salud financiera, gráficos de ingresos vs gastos, distribución de gastos por categorías y metas de ahorro.
2. **Registrador de Gastos**: Teclado táctil interactivo, clasificación, medios de pago y registro rápido.
3. **Objetivos de Ahorro**: Progreso global, metas activas con aportes de dinero y redondeo automático.

## Scripts Disponibles
- `npm run dev`: Inicia el servidor de desarrollo en `http://localhost:5173/`
- `npm run build`: Compila para producción
- `npm run preview`: Previsualiza la compilación de producción
